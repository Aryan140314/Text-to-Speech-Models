# Fish Speech S2 Model

Fish Speech S2 is an advanced LLM-based zero-shot voice cloning engine utilizing VQ-GAN audio tokenization.

## Features
- Ultra-high resolution audio (up to 44.1kHz)
- Multi-lingual zero-shot voice cloning
- LLM backbone with semantic speech tokens

## Quick Start
- Run `install.bat` to initialize dependencies.
- Execute `run.bat` or `python test.py --text "your prompt"` to synthesize speech.
