# XTTS-v2 (Coqui TTS)

XTTS-v2 is a state-of-the-art zero-shot voice cloning model by Coqui AI capable of synthesizing expressive speech in 17+ languages using a 3-second reference audio clip.

## Features
- Zero-Shot Voice Cloning from short reference audio
- Multi-lingual synthesis
- High-fidelity 24kHz audio output

## Usage
- Run `install.bat` to set up environment.
- Run `run.bat` or `python test.py` for inference.
